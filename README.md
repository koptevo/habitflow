# Мне Букет — демо-лендинг

Одностраничный сайт цветочной мастерской. Чистый HTML + CSS + JS, без сборки и зависимостей.
Букеты нарисованы векторно (SVG) — сайт не «поплывёт» без интернета и не требует фотографий, пока их нет.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка, весь контент, SVG-иллюстрации букетов |
| `styles.css` | Стили, сетки, адаптив, анимации появления |
| `script.js` | Меню на телефоне, выбор букета → форма, маска телефона, валидация, «заявка отправлена» |

## Как открыть

Двойной клик по `index.html` — откроется в браузере. Всё работает локально.

## Форма

Сейчас это демо: данные никуда не уходят, показывается сообщение «Заявка отправлена».
Чтобы заявки приходили, нужно подключить одно из:

- Telegram-бот (Webhook) или сервис вроде Formspree / Getform — достаточно поменять обработчик `submit` в `script.js`;
- CRM клиента (если у неё есть форма/вебхук).

## Публикация

- **Netlify Drop** — перетащить папку на netlify.com/drop, ссылка готова за минуту.
- **GitHub Pages** — загрузить три файла в репозиторий, включить Pages.
- Любой хостинг со статикой — просто скопировать файлы.

## Проверено

- Адаптив: 390 px, планшет, десктоп 1440 px.
- Клавиатура, `prefers-reduced-motion`, контраст текста.
- Без внешних картинок; шрифты Cormorant + Inter подгружаются с Google Fonts, при отсутствии сети срабатывает системный Georgia.
